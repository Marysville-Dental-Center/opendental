The release ships the third-party components below next to OpenPmsDental.exe.
Each keeps its own license. For each component this file names the files,
the version in this repository, the copyright holders, the license and where
its source is published. The license texts follow the components: the short

Copyright years are in each project's own license file at its source address.

PDFsharp, MigraDoc and WeCantSpell.Hunspell are built by this project from
their source: git submodules of this repository (third-party/PDFsharp and
third-party/WeCantSpell.Hunspell) pinned to the upstream release commits named
below, compiled by the project files in third-party/build. The source archive
of each release, OpenPmsDental-<version>-source.zip next to the setup, holds
the repository and both submodules at the commits the release was built from
(docs/third-party-source-builds.md).

Files in the repository's "Required dlls" folder that are not listed here are
not part of the release (see docs/third-party-binaries-audit.md). Among them
is a support library for the coming library updates, listed here once a
shipped library uses it: System.Security.Cryptography.Pkcs 8.0.1, by the .NET
Foundation and Contributors under the MIT License, source at
https://github.com/dotnet/runtime. The MariaDB server, the .NET Framework,
the Visual C++ runtime, the WebView2 runtime and the TWAIN data source manager
are installed separately and are not shipped. DICOM images are read and
written by the program's own code, written from the DICOM standard (NEMA
PS3); no DICOM library ships.

GPL compatibility: the components marked "Owner question" below have
licenses whose compatibility with the GNU GPL is not settled; see
docs/port-notes/REL-FILES.md.
