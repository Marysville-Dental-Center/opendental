Open PMS - Dental: third-party notices
======================================

Open PMS - Dental is a fork of Open Dental (c) Open Dental Software, Inc. and
contributors. The program itself is licensed under the GNU General Public
License, version 2 or (at your option) any later version; see LICENSE and
NOTICE.

The release ships the third-party components below next to OpenDental.exe.
Each keeps its own license. For each component this file names the files,
the version in this repository, the copyright holders, the license and where
its source is published. The license texts follow the components: the short
standard texts in full, and the vendor texts kept from Open Dental's license
list in the program (Help > About > View Licenses), under the component's name.
Copyright years are in each project's own license file at its source address.

Files in the repository's "Required dlls" folder that are not listed here are
not part of the release (see docs/third-party-binaries-audit.md). The MariaDB
server, the .NET Framework, the Visual C++ runtime, the WebView2 runtime and
the TWAIN data source manager are installed separately and are not shipped.

GPL compatibility: the components marked "Owner question" below have
licenses whose compatibility with the GNU GPL is not settled; see
docs/port-notes/REL-FILES.md.
