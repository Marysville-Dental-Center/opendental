What this setup does:
- It installs the program files in the program folder (by default C:\Program Files (x86)\Open PMS - Dental). The uninstaller goes to its "uninstall" sub folder.
- It writes FreeDentalConfig.xml (database server, database and user) if the program folder has none. The password is never stored by setup: the program asks for it the first time it starts.
- It does not install or change a database server or a database, and it never touches the A to Z images folder.
- Uninstalling removes the whole program folder, including files that later updates added. The database and the A to Z folder are not touched.

The program folder also gets LICENSE (the GNU GPL version 2, the license of the program's own source files), LICENSE-GPL-3.0.txt (the GNU GPL version 3, under which the program as installed is distributed), LICENSE-AGPL-3.0.txt (the GNU AGPL version 3, under which PDFsharp and MigraDoc ship), LICENSE-LGPL-2.1.txt (the GNU LGPL 2.1, under which the report engine and the spell checker ship), NOTICE, THIRD-PARTY-NOTICES.txt (the licenses of the third-party components), and db\README.md with db\init\new-database.sql (how to create a new office database).
