What this setup does:
- It installs the program files in the program folder (by default C:\Program Files (x86)\Open PMS - Dental). The uninstaller goes to its "uninstall" sub folder.
- It writes FreeDentalConfig.xml (database server, database and user) if the program folder has none. Setup never writes a password, and the program never asks for one. The connection settings tool, OpenPmsDentalDbSettings.exe in the program folder (administrators only), sets up the rest: the office CA certificate and the client certificate, or the database password, which it stores on this computer with Windows DPAPI. Setup opens the tool after the files are installed: for a database server over the network, and, in an interactive install, for a database on this computer too, in password mode (Cancel when the database user has no password). A silent install passes the tool's secrets in a file (/DBSECRETSFILE=).
- The database user on the connection page defaults to opmsd, the program's own database account from the server guide (docs/db-connection-security.md in the source): the program no longer uses root. The tool warns when root is the user for a server over the network.
- A computer with version 0.0: uninstall 0.0 first. Its uninstaller removes the program folder with its FreeDentalConfig.xml, and this setup then sets the connection up as a new install. There is no in-place upgrade from 0.0.
- On a computer that already has FreeDentalConfig.xml (a version after 0.0), setup keeps it. With /DBCA=, /DBPFX=, /DBTHUMBPRINT= or /DBSECRETSFILE= it runs the tool with exactly the switches given; otherwise it only checks the settings and offers the tool when they do not meet this version's connection rule.
- It does not install or change a database server or a database, and it never touches the A to Z images folder.
- Uninstalling removes the whole program folder, including files that later updates added. The database and the A to Z folder are not touched.

The program folder also gets LICENSE (the GNU GPL), LICENSE-LGPL-2.1.txt (the GNU LGPL 2.1, under which the report engine and the spell checker ship), NOTICE, THIRD-PARTY-NOTICES.txt (the licenses of the third-party components), and db\README.md with db\init\new-database.sql (how to create a new office database).

This setup is not digitally signed. Windows SmartScreen may warn about it; compare its SHA-256 with SHA256SUMS.txt of the release.
